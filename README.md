# sage-ai

Public assets for Sage_AI, the product management assistant of the M-PaX System. MIT license.

## What is here

- skills. Sage_AI Skills. Each skill is its own folder with a SKILL.md. Upload the ZIP named in the manifest under Customize, then Skills, in Claude. One ZIP holds one skill.
- sage-ai-context. The System Context, which is the system instructions Sage_AI reads at the start of every mission, the Stub, the AI Meta of each Growth Factor, and the Skeletons. Each change is a new dated file. A change made on the day of the last release replaces that day's file.
- manifest.json. One file that lists every asset with its type, version, date, path, package, and a short release note. Sage_AI checks it for anything new.

Templates are a reserved type with no assets, because the templates are Google Docs.
